# Reevl — 한국 부동산 데이터 (Claude Code 플러그인)

전국 아파트 약 45,000개의 실거래 시세·전세가율·거래량·입지 점수와
리블 AI 가격 예측을 Claude Code에서 바로 조회합니다.

원격 MCP 서버(`https://reevl.co.kr/api/mcp`)에 붙는 얇은 플러그인입니다.
설치할 것도, 실행할 것도 없습니다 — 인증도 필요 없습니다.

## 설치

```
/plugin marketplace add <배포 저장소>
/plugin install reevl@<마켓플레이스 이름>
```

로컬에서 시험하려면:

```
claude --plugin-dir ./plugins/reevl
```

## 무엇이 들어 있나

| 구성 | 내용 |
|---|---|
| MCP 서버 | `reevl` — 원격 HTTP(Streamable) |
| 스킬 | `korean-real-estate` — 축·단위 함정과 답변 규칙 |

### 도구 4종

- **`describe_fields`** — 쓸 수 있는 모든 축과 **단위**, 값 분포, 시도별 단지 수
- **`search_apartments`** — 지역·가격·브랜드·시공사·세대수·전세가율·AI예측 등 조건 검색
- **`get_apartment`** — 단지 하나의 전 축(기본·가격·전세월세·거래·등락·AI예측·입지·건물)
- **`list_articles`** — 리블이 발행한 부동산 브리핑 목록

## 예시

```
서울 강남구에서 20억 이하 대단지 아파트 찾아줘
마포구 10~15억 아파트 중 전세가율 높은 순으로
래미안 브랜드 단지 중 준공 5년 이내인 곳
```

## 주의

- **참고용 통계입니다.** 투자 자문이나 중개가 아니며, 실제 거래 판단의 책임은
  이용자에게 있습니다.
- 가격 단위는 **만원**입니다(15억 = `150000`).
- 지역은 `region`이 아니라 `sido`·`gu`·`dong`으로 나눠 넣습니다.

## 데이터 출처

국토교통부 실거래가, 한국부동산원, K-apt(공동주택관리정보시스템),
KOSIS, 한국은행 ECOS, 국토교통부 V-World 등 공공데이터를 정규화해 제공합니다.
각 응답에 출처와 갱신일이 함께 반환됩니다.
